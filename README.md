# Automath Project

## All tasks
In the "All Tasks" folder, you'll find all the tasks and their generated code (for HTML files, the JavaScript code is the actual experiment code). Please note that the (zipped) jsPsych library has been redistributed to simplify task execution, but please install it directly from the source [github.com/jspsych](https://github.com/jspsych/jsPsych).

## Analyses
In the "Analyses" folder, you will find all the necessary analyses (with the exception of those performed using CSV files and done via JASP). Files starting with 0 correspond to pre-processing. It is best to start with the strategy analyses, then the cognitive predictor tasks, and finally the verification and production tasks. Files starting with 1 correspond to the main analyses. Finally, files starting with 2 correspond to exploratory analyses (many exploratory analyses can be performed by examining the perParticipant output once the run is complete).
